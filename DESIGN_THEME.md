# Beautiful Quran Design Theme

The application now features a **colorful, floral Islamic design** inspired by traditional Quran book covers with ornate patterns and beautiful colors.

## Color Palette

### Primary Colors
- **Gold/Brown**: `#b8860b`, `#daa520`, `#cd853f` - For borders, accents, and highlights
- **Teal/Turquoise**: `#149696` - For decorative elements and secondary accents
- **Off-White/Light Grey**: `#f5f5f0`, `#e8e8e3`, `#f0f0eb` - Background colors
- **Text**: `#2c2c2c` - Dark text for readability

### Design Elements

1. **Ornate Borders**
   - Double borders with inner decorative frames
   - Gold/brown outer borders
   - Teal inner borders for contrast
   - Rounded corners (20-25px radius)

2. **Decorative Symbols**
   - ✦ (Star) - Used for decorative accents
   - ❋ (Floral) - Used for pattern elements
   - Positioned strategically around cards and containers

3. **Gradient Backgrounds**
   - Light grey to off-white gradients
   - Subtle radial gradients for depth
   - Repeating geometric patterns

4. **Card Design**
   - White/off-white backgrounds with transparency
   - Gold borders with teal accents
   - Double-layered borders (outer + inner)
   - Shadow effects with gold/teal tints
   - Hover effects with scale and shadow

5. **Typography**
   - Gold gradient text for titles
   - Teal color for secondary text
   - Serif fonts (Georgia) for headings
   - Clear, readable sans-serif for body text
